# Dawn Sogni — Music

A simple music site: songs with audio, cover and lyrics. Hosted on GitHub Pages.

- **Site:** https://jayseth34.github.io/Dawnsogni-album/
- **Admin:** https://jayseth34.github.io/Dawnsogni-album/admin.html

In admin: add a song → title, audio, cover, lyrics → **Publish**. It's live immediately.
Lyrics can be plain, or synced with `[mm:ss.xx]` at the start of each line.
